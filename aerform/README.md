# AERFORM — кроссовки

Витрина экспериментальной коллекции по видеореференсу: главный экран, детали конструкции, четыре цвета кроссовок, интерактивная схема материалов и карточка выбора размера EU 36–45.

Откройте `dist/index.html` или запустите локальный HTTP-сервер из папки `dist`. HTML, CSS и JavaScript без сборки. Основные файлы: `dist/index.html`, `dist/style.css`, `dist/app.js`. Изображения: `dist/assets/`.

В блоке материалов выбор части меняет подробное описание: состав, расположение, назначение и уход. Верх — текстильная сетка с TPU-накладками; промежуточная подошва — пена EVA; протектор — резина. Схема условная и не в масштабе.

Название бренда, конструкция и изображения демонстрационные. Состав реального товара, размерную сетку и рекомендации производителя необходимо уточнить до продаж. Оплата и оформление заказа не подключены. Выбор цвета и размера сохраняется только в браузере посетителя, отдельно от прежнего выбора одежды.

Изображения созданы встроенным ImageGen. Промпты: чёрный технический кроссовок с сетчатым верхом, объёмной скульптурной подошвой и синими бликами на прозрачном фоне; каталог из четырёх кроссовок в сетке 2×2 — салатовый, розовый, оранжевый и синий, одинаковый ракурс, прозрачный фон. Каталог разделён на четыре файла, изображения оптимизированы в WebP.
